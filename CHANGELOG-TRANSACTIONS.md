# Transactions overview update

- Added a dedicated Transactions destination in the More menu.
- Added a combined chronological list of sales, other income, and expenses using existing Sale and Expense records.
- Added filters for All, Sales, Income, and Expenses.
- Added summary totals for sales, other income, expenses, and the simple combined net figure.
- No Room entities, columns, migrations, or existing records were changed.

Limitations: this is a read-only overview. Editing/deleting entries remains in the existing Sales and Expense screens. Sales are shown by invoice total; the net figure is not a formal cash-balance calculation and does not account for unpaid customer dues or inventory cost flows.
